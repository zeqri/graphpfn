# MolPFN

**MolPFN** is a prior-data fitted network for **molecular property prediction** (graph-level regression and classification). It keeps the tabular foundation model [LimiX-16M](https://github.com/limix-ldm/LimiX) frozen and trains a small **graph pooler** (a message-passing `PoolingGNN` plus per-block graph adapters) on top of it. The pooler turns each molecule into a single row that LimiX can reason over in context.

The pooler is trained **only on synthetic data**: molecule-skeleton graphs whose topology is calibrated to real ZINC molecules (size, bond density, ring-size mix), with atom features and labels generated by a causal MLP structural causal model. Real ZINC-12k is used only to select the best checkpoint. At test time, MolPFN predicts properties by in-context learning, with no finetuning. It can optionally use pretrained molecule embeddings (Molbert, MolDeBERTa).

MolPFN is a derivative work of [GraphPFN](https://github.com/yandex-research/graphpfn) ([paper](https://arxiv.org/abs/2509.21489)), and reuses its synthetic prior and graph modules. It is an independent project and is not affiliated with or endorsed by the GraphPFN authors or Yandex. MolPFN's training and evaluation pipeline is in [`paper/dev_prior_final/`](paper/dev_prior_final/), with supporting additions and modifications in [`paper/lib/`](paper/lib/).

## What you need

| Item | Where it goes | How to get it |
|---|---|---|
| Python 3.12 virtual environment | — | `venv` + `pip` (see [Setup](#setup)) |
| GPU with bf16 support | — | Training uses 4 GPUs by default. Evaluation uses 1. |
| LimiX-16M backbone | `paper/checkpoints/LimiX-16M.ckpt` | Download from Hugging Face (see [Setup](#setup)). **Not** included in the repository, because it has its own license. |
| MolPFN pooler checkpoint | e.g. `checkpoints/pooler_checkpoint_best.pt` | Train it yourself ([Training](#1-train-the-pooler)) or use a released checkpoint |
| MoleculeNet raw data | `datasets/moleculenet/<dataset>/{raw,processed}` | `python datasets/download_datasets.py` (see [Setup](#setup)) |
| MoleculeNet scaffold splits | `datasets/moleculenet/<dataset>/split/{scaffold_split,split_info}.json` | `python datasets/make_scaffold_splits.py` (see [Setup](#setup)) |
| ZINC-12k | `datasets/zinc/` | `python datasets/download_datasets.py` |
| AQSOL | `datasets/aqsol/` (`data_curated.csv` included) | `python datasets/download_datasets.py` downloads the raw files |
| Mole-BERT and MolDeBERTa models | `embeddings/checkpoints/` | Download from GitHub and Hugging Face (see [Setup](#setup)) |
| Molecule embeddings | `embeddings/<Molbert\|MolDeBERTa>/<dataset>/` | `bash paper/embedding/run_embeddings.sh` (see [Setup](#setup)) |

Datasets covered: **ESOL, FreeSolv, Lipophilicity, ZINC, AQSOL** (regression) and **BACE, BBBP, ClinTox, SIDER** (classification).

## Setup

**1. Create a Python 3.12 virtual environment**

```bash
python3.12 -m venv venv
source venv/bin/activate

pip install torch==2.4.0 --index-url https://download.pytorch.org/whl/cu118
pip install dgl==2.4.0 -f https://data.dgl.ai/wheels/torch-2.4/cu118/repo.html
pip install torch-geometric rdkit huggingface_hub numpy scipy scikit-learn pandas \
    einops loguru delu networkx numba pyyaml tomli-w tqdm \
    rtdl_num_embeddings rtdl_revisiting_models optuna kditransform ogb
```


**2. Download the LimiX-16M backbone** to `paper/checkpoints/LimiX-16M.ckpt`:

```bash
cd paper   # from the repository root
python -c "from huggingface_hub import hf_hub_download; hf_hub_download('stableai-org/LimiX-16M', 'LimiX-16M.ckpt', local_dir='checkpoints')"
```

**3. Download the datasets.** [`datasets/download_datasets.py`](datasets/download_datasets.py) downloads and processes all nine datasets with `torch_geometric` into `datasets/`, where the training, evaluation and embedding scripts look for them. Run it from the repository root:

```bash
python datasets/download_datasets.py
```

| Dataset | Saved to |
|---|---|
| MoleculeNet: BACE, BBBP, ClinTox, ESOL, FreeSolv, Lipophilicity, SIDER | `datasets/moleculenet/<dataset>/{raw,processed}` |
| ZINC-12k (train / val / test) | `datasets/zinc/{raw,subset/processed}` |
| AQSOL (train / val / test) | `datasets/aqsol/{raw,processed}` |

Datasets already on disk are not downloaded again. Use `--datasets bace zinc ...` to download only some of them. For each MoleculeNet dataset, the script checks that the downloaded CSV is byte-identical (same sha256) to the one used in the paper, and exits with an error (printing `[MISMATCH]`) if not. The scaffold splits are row indices into that CSV, so a different file would give different splits and results.

**4. Generate the scaffold splits.** [`datasets/make_scaffold_splits.py`](datasets/make_scaffold_splits.py) splits each MoleculeNet dataset 80/10/10 by Bemis-Murcko scaffold, so no scaffold is shared between train, valid and test. Run it from the repository root, after step 3:

```bash
python datasets/make_scaffold_splits.py
```

It writes two files to `datasets/moleculenet/<dataset>/split/`:

- `scaffold_split.json`: the train / valid / test row indices into the downloaded CSV
- `split_info.json`: the sha256 and row count of that CSV, and the rows RDKit cannot parse (these are left out of every split)

The splits are deterministic, so with the CSVs from step 3 they are identical to the ones used in the paper. ZINC and AQSOL use their official `torch_geometric` train / val / test splits and need no split files.

**5. Install the embedding dependency.** The evaluation scripts and the TabPFN v3 baseline use pretrained Molbert and MolDeBERTa molecule embeddings, which you generate in steps 6 and 7. MolDeBERTa needs `transformers`:

```bash
pip install transformers==4.56.2
```

**6. Download both pretrained embedding models** to `embeddings/checkpoints/`, from the repository root:

```bash
mkdir -p embeddings/checkpoints

# Mole-BERT: official code (loader.py, model.py) plus the pretrained GIN weights (model_gin/Mole-BERT.pth)
git clone https://github.com/junxia97/Mole-BERT.git embeddings/checkpoints/Mole-BERT
git -C embeddings/checkpoints/Mole-BERT checkout 2feff8a33e3634b66b7408e2e2780fc9d960909f

# MolDeBERTa: model weights and tokenizer
python -c "from huggingface_hub import snapshot_download; snapshot_download('SaeedLab/MolDeBERTa-base-123M-mtr', revision='7d06a5f39098837a6f33ed095e2fa7706e30f8b9', local_dir='embeddings/checkpoints/MolDeBERTa-base-123M-mtr')"
```

You should now have:

```
embeddings/checkpoints/
├── Mole-BERT/
│   ├── loader.py
│   ├── model.py
│   └── model_gin/Mole-BERT.pth
└── MolDeBERTa-base-123M-mtr/
    ├── config.json
    ├── model.safetensors
    └── tokenizer files (tokenizer.json, vocab.json, merges.txt, ...)
```

**7. Generate the embeddings**, after steps 3 and 4. [`paper/embedding/run_embeddings.sh`](paper/embedding/run_embeddings.sh) encodes all nine datasets with both models and writes them to `embeddings/{MolDeBERTa,Molbert}/<dataset>/`. It reads the models from `embeddings/checkpoints/`, and refuses to encode a MoleculeNet dataset whose CSV sha256 differs from the one in `split/split_info.json`:

```bash
source venv/bin/activate          # or pass VENV=/path/to/venv
bash paper/embedding/run_embeddings.sh
```

It runs on the CPU by default. Set `DEVICE=cuda` to use a GPU. To run one encoder or a subset of datasets, call the scripts directly from `paper/embedding/`:

```bash
cd paper/embedding
python moldeberta_encode_moleculenet.py --datasets esol lipo aqsol   # MolDeBERTa, MoleculeNet + AQSOL
python moldeberta_encode_zinc.py                                     # MolDeBERTa, ZINC
python molebert_encode_all.py --datasets bace zinc                   # Mole-BERT, any dataset
```

Each dataset produces `<dataset>_embeddings_{train,valid,test}.npy` and `<dataset>_meta.json`. Molecules that cannot be encoded are dropped, never stored as zero vectors. Each `<dataset>_meta.json` lists the kept rows for every split (`split_idx`, or `graph_index` for MolDeBERTa AQSOL) and the dropped ones (`failed_indices`). The evaluation scripts use these lists to line up embeddings with labels.

## 1. Train the pooler

Activate the environment and run this from the `paper/` directory:

```bash
cd paper
torchrun --nproc_per_node=4 dev_prior_final/train_pooler.py \
    --min-molecules 1000 --max-molecules 2000 \
    --n-sampler-workers 11 --prefetch-factor 4 \
    --n-steps 10000 --lr 0.001 \
    --zinc-context 2000 --zinc-query 500
```

**Single GPU:** run the script with `python` instead of `torchrun`:

```bash
cd paper
python dev_prior_final/train_pooler.py \
    --min-molecules 1000 --max-molecules 2000 \
    --n-sampler-workers 11 --prefetch-factor 4 \
    --n-steps 10000 --lr 0.001 \
    --zinc-context 2000 --zinc-query 500
```

Each optimizer step averages gradients over 20 synthetic datasets per GPU. A single-GPU run therefore sees 20 datasets per step instead of 80 on 4 GPUs, so its results will differ from the 4-GPU setup. To match it, set `N_GRADIENT_ACCUMULATION_STEPS = 80` in `train_pooler.py`; each step then takes about 4 times as long.

[`paper/dev_prior_final/train.sh`](paper/dev_prior_final/train.sh) is an example SLURM script (4 GPUs, 6 h). Edit its `#SBATCH` account, the environment it activates and the `cd` path before you use it.

| Argument | Default | Meaning |
|---|---|---|
| `--min-molecules` / `--max-molecules` | 300 / 3000 | Range for the number of molecules per synthetic training dataset (log-uniform) |
| `--n-steps` | 1000 | Total optimizer steps |
| `--lr` | 0.001 | Peak learning rate (cosine schedule, 10% warmup) |
| `--zinc-context` / `--zinc-query` | 2000 / 500 | ZINC context and query sizes used for checkpoint selection |
| `--n-sampler-workers` / `--prefetch-factor` | 6 / 4 | CPU workers per GPU that generate synthetic data |
| `--zinc-root` | `datasets/zinc` | Where ZINC is stored or downloaded |

**Outputs** are written to `paper/dev_prior_final/output/train_pooler/molecules_<min>_<max>_zinc_<ctx>_<qry>_n_steps_<n>_lr_<lr>/`:

- `pooler_checkpoint_best.pt`: the checkpoint with the lowest ZINC validation MAE. **Use this one for evaluation.**
- `pooler_checkpoint.pt`: the latest state. If you rerun with the same arguments, training resumes from it automatically.
- `training_log.jsonl`: per-evaluation metrics (synthetic R² and ZINC MAE).

## 2. Evaluate

Each evaluation script evaluates both **MolPFN** and a plain **LimiX** baseline in one run, on the same molecules, splits and labels:

| Pipeline (output key) | Model | Input |
|---|---|---|
| `baseline_x_plus_extra_features` | MolPFN | Molecule graph; atom features = 9 MoleculeNet columns + 31 RDKit columns |
| `x_plus_extra_features_molebert_augmented` | MolPFN | Same, plus the pretrained molecule embedding as one more LimiX feature group |
| `baseline_extra_features_only` | MolPFN | Molecule graph; atom features = the 31 RDKit columns only (MoleculeNet datasets only) |
| `extra_features_only_molebert_augmented` | MolPFN | Same, plus the pretrained molecule embedding (MoleculeNet datasets only) |
| `molebert_limix` | LimiX | The pretrained molecule embedding as plain tabular features, with no pooler and no graph |

The MolPFN pipelines pass each molecule through the trained pooler into the frozen LimiX backbone. The LimiX pipeline gives the same frozen backbone only the embeddings. ZINC and AQSOL run the first two MolPFN pipelines and the LimiX pipeline. The output keys are named `molebert_*` for both embedding models; the model actually used is recorded under `embedding_model` in the output JSON. `--skip-embedding-limix` skips the LimiX pipeline, and `--skip-embeddings` skips every pipeline that uses embeddings.

Each evaluation script runs on one GPU and finds the datasets, embeddings and LimiX backbone through paths relative to the script, so it can be launched from any directory. The only required inputs are the pooler checkpoint and the embedding model.

```bash
cd paper/dev_prior_final/evaluation
CKPT=../../../checkpoints/pooler_checkpoint_best.pt

# Regression
python eval_moleculenet_regression.py --dataset esol     --pooler-checkpoint $CKPT --embedding-model Molbert --n-ensemble 1
python eval_moleculenet_regression.py --dataset freesolv --pooler-checkpoint $CKPT --embedding-model Molbert --n-ensemble 1
python eval_moleculenet_regression.py --dataset lipo     --pooler-checkpoint $CKPT --embedding-model Molbert --n-ensemble 10 --max-train 2000
python eval_zinc.py  --pooler-checkpoint $CKPT --embedding-model Molbert --max-train 2000 --n-ensemble 10
python eval_aqsol.py --pooler-checkpoint $CKPT --embedding-model Molbert --max-train 2000 --n-ensemble 10

# Classification
python eval_bace.py    --pooler-checkpoint $CKPT --embedding-model Molbert
python eval_bbbp.py    --pooler-checkpoint $CKPT --embedding-model Molbert
python eval_clintox.py --pooler-checkpoint $CKPT --embedding-model Molbert
python eval_sider.py   --pooler-checkpoint $CKPT --embedding-model Molbert --tasks all
```

Replace `Molbert` with `MolDeBERTa` to use the other embeddings.

**Common options** (shared by all evaluation scripts):

| Argument | Default | Meaning |
|---|---|---|
| `--pooler-checkpoint` | — | **Required.** Pooler `.pt` to evaluate |
| `--embedding-model` | — | **Required.** `Molbert` or `MolDeBERTa` |
| `--backbone-checkpoint` | `paper/checkpoints/LimiX-16M.ckpt` | Frozen LimiX backbone |
| `--embeddings-root` | `embeddings/` | Root holding `<model>/<dataset>/` |
| `--moleculenet-root` / `--zinc-root` / `--aqsol-root` | `datasets/<name>` | Dataset locations |
| `--limix-seed` | 0 | Seed for the permutation ensemble |
| `--limix-n-members` | 8 | Permutation-ensemble members per pipeline |
| `--no-ema` | off | Use raw instead of EMA pooler weights |
| `--skip-embeddings` / `--skip-embedding-limix` | off | Skip the embedding-augmented pipelines |
| `--output-json` | `outputs/<model>/<name>.json` | Where to write metrics |
| `--device` | `cuda` if available | Device |

### Full sweep

[`paper/dev_prior_final/evaluation/run_eval.sh`](paper/dev_prior_final/evaluation/run_eval.sh) runs every dataset with both embedding models and LimiX seeds 1–5, sequentially on one GPU. Set `VENV` to activate a virtualenv first:

```bash
POOLER_CHECKPOINT=checkpoints/pooler_checkpoint_best.pt \
bash paper/dev_prior_final/evaluation/run_eval.sh

# only ZINC and AQSOL
POOLER_CHECKPOINT=checkpoints/pooler_checkpoint_best.pt DATASETS="zinc aqsol" \
bash paper/dev_prior_final/evaluation/run_eval.sh
```

`EMBEDDING_MODELS` and `SEEDS` narrow the sweep the same way. Seeds whose result already exists are skipped unless `OVERWRITE=1` is set. Results are written to `paper/dev_prior_final/evaluation/outputs/<model>/<dataset>/eval.limixseed<seed>.json`.

## 3. TabICL baseline

[`paper/dev_prior_final/evaluation/TabICL/eval_tabicl.py`](paper/dev_prior_final/evaluation/TabICL/eval_tabicl.py) is an embeddings-only baseline: the Molbert or MolDeBERTa embeddings (from [Setup](#setup) step 7) are used as plain tabular features for TabICL in-context learning, with no pooler and no graphs. It is the TabICL counterpart of the LimiX pipeline (`molebert_limix`) in the evaluation scripts, and uses the same molecules, splits, labels, context sizes and metrics.

It runs in the MolPFN environment. The TabICL code is included in [`paper/vendor/tabicl`](paper/vendor/tabicl); its weights are not.

**1. Download the TabICL v2 checkpoints** to `paper/checkpoints/tabicl/`, from the repository root:

```bash
python -c "from huggingface_hub import hf_hub_download as d; [d('jingang/TabICL', f, local_dir='paper/checkpoints/tabicl') for f in ('tabicl-classifier-v2-20260212.ckpt', 'tabicl-regressor-v2-20260212.ckpt')]"
```

If a checkpoint is missing when you run the script, TabICL downloads it to that folder on first use. To keep the checkpoints somewhere else, pass `--checkpoint-dir DIR`.

**2. Run it:**

```bash
cd paper/dev_prior_final/evaluation/TabICL

# Classification
python eval_tabicl.py --dataset bace    --embedding-model Molbert
python eval_tabicl.py --dataset bbbp    --embedding-model Molbert
python eval_tabicl.py --dataset clintox --embedding-model Molbert
python eval_tabicl.py --dataset sider   --embedding-model Molbert --tasks all

# Regression (per-dataset defaults for --max-train / --n-ensemble match the MolPFN evaluation)
python eval_tabicl.py --dataset esol     --embedding-model Molbert
python eval_tabicl.py --dataset freesolv --embedding-model Molbert
python eval_tabicl.py --dataset lipo     --embedding-model Molbert
python eval_tabicl.py --dataset zinc     --embedding-model Molbert
python eval_tabicl.py --dataset aqsol    --embedding-model Molbert
```

Replace `Molbert` with `MolDeBERTa` to use the other embeddings. Use `--tabicl-seed` to set TabICL's `random_state` (default 0) and `--n-estimators` for its ensemble size (default 8). Results are written to `paper/dev_prior_final/evaluation/TabICL/outputs/<model>/tabicl_<dataset>.json` unless `--output-json` is given.

**Full sweep.** [`run_eval_tabicl.sh`](paper/dev_prior_final/evaluation/TabICL/run_eval_tabicl.sh) runs every dataset with both embedding models and `--tabicl-seed` 1–5, sequentially on one GPU. It checks that both checkpoints exist before it starts; set `TABICL_CHECKPOINT_DIR` if they are not in `paper/checkpoints/tabicl/`, and `VENV` to activate a virtualenv first:

```bash
bash paper/dev_prior_final/evaluation/TabICL/run_eval_tabicl.sh

# only ZINC and AQSOL
DATASETS="zinc aqsol" bash paper/dev_prior_final/evaluation/TabICL/run_eval_tabicl.sh
```

`EMBEDDING_MODELS` and `SEEDS` narrow the sweep the same way.

Results are written to `outputs/<model>/<dataset>/tabicl.seed<seed>.json`.

## 4. TabPFN v3 baseline

[`paper/dev_prior_final/evaluation/TabPFNv3/eval_tabpfnv3.py`](paper/dev_prior_final/evaluation/TabPFNv3/eval_tabpfnv3.py) is an embeddings-only baseline: the Molbert or MolDeBERTa embeddings (from [Setup](#setup) step 7) are used as plain tabular features for TabPFN v3 in-context learning, with no pooler and no graphs. It uses the same datasets, splits, labels, protocol and metrics as the [TabICL baseline](#3-tabicl-baseline).

Neither the TabPFN code nor its weights are included in this repository. Both are covered by the [Prior Labs license](https://github.com/PriorLabs/TabPFN), which you must accept yourself.

**1. Create a separate environment.** `tabpfn` needs `torch>=2.5`, while the MolPFN environment uses `torch==2.4`. The script needs neither DGL, `torch_geometric` nor RDKit.

```bash
python3.12 -m venv tabpfn_env
source tabpfn_env/bin/activate
pip install "tabpfn==<VERSION>" numpy scikit-learn
```

**2. Get the TabPFN v3 checkpoints** (`tabpfn-v3-classifier-v3_default.ckpt` and `tabpfn-v3-regressor-v3_default.ckpt`) from the gated Hugging Face repository `Prior-Labs/tabpfn_3`. The script reads them from `paper/checkpoints/tabpfnv3/`. If they are not there, `tabpfn` downloads them to that folder the first time you run the script. The first download needs a one-time license acceptance (browser login; the token is stored under `~/.cache/tabpfn`). To keep the checkpoints somewhere else, pass `--checkpoint-dir DIR`.

**3. Run it:**

```bash
cd paper/dev_prior_final/evaluation/TabPFNv3

# Classification
python eval_tabpfnv3.py --dataset bace    --embedding-model Molbert
python eval_tabpfnv3.py --dataset bbbp    --embedding-model Molbert
python eval_tabpfnv3.py --dataset clintox --embedding-model Molbert
python eval_tabpfnv3.py --dataset sider   --embedding-model Molbert --tasks all

# Regression (per-dataset defaults for --max-train / --n-ensemble match the MolPFN evaluation)
python eval_tabpfnv3.py --dataset esol     --embedding-model Molbert
python eval_tabpfnv3.py --dataset freesolv --embedding-model Molbert
python eval_tabpfnv3.py --dataset lipo     --embedding-model Molbert
python eval_tabpfnv3.py --dataset zinc     --embedding-model Molbert
python eval_tabpfnv3.py --dataset aqsol    --embedding-model Molbert
```

Replace `Molbert` with `MolDeBERTa` to use the other embeddings. Use `--tabpfn-seed` to set TabPFN's `random_state` (default 0). `--n-estimators` defaults to 8, not v3's `"auto"`, to match TabICL. Results are written to `paper/dev_prior_final/evaluation/TabPFNv3/outputs/<model>/tabpfnv3_<dataset>.json` unless `--output-json` is given.

**Full sweep.** [`run_eval_tabpfnv3.sh`](paper/dev_prior_final/evaluation/TabPFNv3/run_eval_tabpfnv3.sh) runs every dataset with both embedding models and `--tabpfn-seed` 1–5, sequentially on one GPU. Set `TABPFN_CHECKPOINT_DIR` if the checkpoints are not in `paper/checkpoints/tabpfnv3/`, and `VENV` to activate the TabPFN environment first:

```bash
bash paper/dev_prior_final/evaluation/TabPFNv3/run_eval_tabpfnv3.sh

# only ZINC and AQSOL
DATASETS="zinc aqsol" bash paper/dev_prior_final/evaluation/TabPFNv3/run_eval_tabpfnv3.sh
```

`EMBEDDING_MODELS` and `SEEDS` narrow the sweep the same way. Results are written to `outputs/<model>/<dataset>/tabpfnv3.seed<seed>.json`.

## 5. KNN baseline

[`paper/dev_prior_final/evaluation/KNN/eval_knn.py`](paper/dev_prior_final/evaluation/KNN/eval_knn.py) is an embeddings-only k-nearest-neighbours baseline: the Molbert or MolDeBERTa embeddings (from [Setup](#setup) step 7) are used as plain tabular features for scikit-learn's `KNeighborsClassifier` / `KNeighborsRegressor`, with no pooler and no graphs. It uses the same molecules, splits and labels as the [TabICL baseline](#3-tabicl-baseline), and runs on the CPU in the MolPFN environment.

The features are standardized on the train split. For each task, every combination of distance (`euclidean`, `cosine`) and `k` (1, 3, 5, 7, 9, 11, 15, 21, 31, 51) is fit on train and scored on valid. The combination with the best valid score is selected and its test metrics are reported. By default the valid score is ROC-AUC for classification, RMSE for ESOL, FreeSolv and Lipo, and MAE for ZINC and AQSOL.

Run all nine datasets with both embedding models:

```bash
cd paper/dev_prior_final/evaluation/KNN

for m in Molbert MolDeBERTa; do
    python eval_knn.py --dataset all --embedding-model $m
done
```

Use `--dataset` with one or more dataset names to run a subset, `--select-by` to change the selection metric, `--k-grid` and `--distances` to change the search grid, and `--weights distance` for distance-weighted neighbours. Results are written to `paper/dev_prior_final/evaluation/KNN/outputs/<model>/knn_<dataset>.json` unless `--output-json` is given.

├── checkpoints/               # MolPFN pooler checkpoint(s)

    ├── checkpoints/           # LimiX-16M.ckpt, tabicl/, tabpfnv3/ (downloaded)
    ├── embedding/             # scripts that generate embeddings/
    ├── dev_prior_final/       # MolPFN
    │   ├── train_pooler.py    # pooler training on the synthetic molecule prior
    │   ├── prior_config.py    # base synthetic-molecule prior

    │   └── evaluation/        # per-dataset evaluation scripts + run_eval.sh; TabICL/, TabPFNv3/ and KNN/ baselines
